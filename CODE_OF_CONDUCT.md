# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1][covenant] as its
code of conduct. The canonical text governs; this page states how it is applied
here and how to report a problem.

## What it means in this project

- Keep discussion respectful, specific, and about improving the product.
- Critique the work, not the person. Assume the other side is trying to make
  something better.
- Do not post private customer data, personal data, credentials, private
  transcripts, or confidential company information in issues, pull requests,
  discussions, or examples. Use synthetic records on `.invalid`, `.example`, or
  `example.com` domains.
- Harassment, discrimination, personal attacks, and deliberate disruption are
  not acceptable in any project space, public or private.

This applies in every project space — issues, pull requests, discussions,
commits, and any place where someone is representing the project.

## Reporting

Report conduct concerns privately to **conduct@zentrik.ai**. Include what
happened, where, and any links; you do not need to have resolved it yourself
first.

Reports are read by the maintainers, kept confidential, and acknowledged. A
reporter is never required to interact with the person they reported. A
maintainer who is the subject of a report recuses themselves from handling it.

Security vulnerabilities go through [SECURITY.md](./SECURITY.md) instead, which
has a private reporting path of its own.

## What happens next

Following the Covenant's enforcement ladder, and depending on severity and
pattern: a private correction, a warning with conditions, a temporary ban from
project spaces, or a permanent ban. Sensitive content posted publicly is removed
first, then handled.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
