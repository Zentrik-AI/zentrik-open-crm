# Public Brand Assets

These assets are prepared for public-facing Open CRM surfaces. They use **The
Signal Workshop** brand archetype: a practical open workshop where account
signals, user feedback, source evidence, agent work, human review, releases, and
outcomes stay connected.

The kit combines one AI-generated abstract backdrop with deterministic text and
real product screenshots, so the product UI remains truthful and the copy stays
crisp.

## Style Direction

- calm, useful, technical, and source-grounded
- Signal Workshop: workbench over spaceship, receipts over vibes
- real UI screenshots instead of fake generated product screens
- white canvas, ink navy, Picton/Zentrik blue, signal blue, teal review,
  restrained amber, and outcome green
- no glossy futurism, no stock photography, no decorative blobs, no fake users,
  no robots, no brains, no rockets
- text rendered deterministically outside the image model

## Generation Prompt

The backdrop was generated with the built-in image generation tool using this
direction:

> Create the final "Signal Workshop" brand backdrop for Zentrik Open CRM: an
> open-source CRM where account signals and user feedback become source-grounded
> next actions, product ideas, agent work, human review, releases, and outcome
> checks. Bright minimal product-work studio table, abstract and editorial, no
> people, no plants, no wood texture, no literal app UI, no readable text. On
> the right third, a clean open workshop system: small incoming source tiles,
> layered evidence receipts with no text, a transparent moderation/review gate,
> neatly stacked product-work cards, a compact release stack, and an outcome
> marker. Thin connector lines preserve provenance from inputs to outputs. Wide
> 16:9 landscape, safe copy area across the left 55%, visual mass on right 40%,
> a small horizontal heartbeat/trace line crossing the lower third. Off-white
> canvas, ink navy, deep navy, Picton blue, muted signal blue, teal review,
> small amber work markers, small outcome green markers.

Future assets should keep generated visuals abstract and use real app
screenshots for product truth.

## Production Rule

Do not ask the image model to render product UI, repository names, feature
claims, or launch copy. Generate abstract visual texture only, then place copy,
marks, screenshots, and any exact labels deterministically.
